## MVP этапа 1
- Поднять локальный React + TypeScript frontend и backend API, PostgreSQL через Docker Compose (или документировать эквивалент при отсутствии Docker).
- Миграции основных таблиц: people, projects, staff_users, memberships, project_contacts, events, registrations, audit_log; расширение авторизационных таблиц — следующий этап.
- Временно локальная тестовая авторизация работников с безопасным серверным хранением сессий; подготовить заменяемый интерфейс auth.
- Интерфейс: меню CRM, переключатель проекта, список проектов, карточки/таблица контактов, создание мероприятия (название, дата, время, часовой пояс, slug), список регистраций.
- Роли platform_owner, project_admin, manager, viewer, проверка на backend; недоступные проекты возвращают 403/404 без утечек.
- Seed: два демонстрационных проекта, один общий person и две отдельные карточки project_contacts.
- CRUD и аудит изменений (без чувствительных данных в журнале).
- Автотесты: изоляция проектов; невозможность увидеть чужую историю; повторная регистрация не создаёт дубликат; разные часовые пояса; уникальность slug; запрет подмены project_id.
- README с командами запуска/остановки и результатами тестов.
- UI должен быть универсальным без названий AI Academy в общем шаблоне, тёмно-зелёный + салатовый акцент.

## Этап 2, НЕ делать автоматически
- Email OTP + magic link, ограничение попыток, отправка письма.
- Подключение Telegram/MAX с подтверждением через реальные API и вебхуки.
- Привязка подтверждённого номера по поддерживаемым провайдером механизмам.
- Политики согласий, эксплуатационный аудит, отчёты, публикация.

## Критерии завершения этапа 1
Локальная CRM запускается; реализован переключатель проектов; права проверяются на сервере; тесты изоляции проходят; два проекта хранят раздельную историю одного и того же человека; данные и список мероприятий сохраняются после перезапуска. Отчёт о фактически выполненном с доказательствами тестирования.
