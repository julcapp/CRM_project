# Универсальная Multi-Project CRM
Версия проекта: 0.1 (проектирование), дата: 2026-11-13.
Основная среда: Windows Home-Boss, Codex.
Статус: только проектная документация; код, деплой и реальные интеграции ещё не выполнены.

## Цель
Компактная CRM по мотивам базовых возможностей amoCRM: участники, мероприятия, регистрации и воронка, задачи, статистика, роли. Одна система для разных проектов, единая идентичность человека и отдельная история в каждом проекте.

## Согласованное решение
Вариант Б: общий people для идентификации, отдельный project_contacts (карточка участника в проекте), отдельные registrations, tasks, events и notes для каждого проекта. Работник проекта не видит данные другого проекта только из-за совпадения человека.

## Правила
- Никакого SMS.
- Подтверждение Email через 6-значный код ИЛИ одноразовую ссылку.
- После подтверждения Email пользователь указывает телефон, выбирает Telegram или MAX и подтверждает привязку через бота.
- Регистрация мероприятия завершается после серверного подтверждения требуемых шагов.
- У каждого мероприятия название, дата, время, часовой пояс, своя ссылка/форма; используется один шаблон.
- Проекты могут иметь разные бренды и настройки; общий шаблон не содержит AI Academy.
- По умолчанию права ограничены проектом; общий доступ только владельцу платформы.
- Не модифицировать существующие production-системы без отдельного согласования.
